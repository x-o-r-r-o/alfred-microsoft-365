# Microsoft 365

Microsoft Teams, OneNote and Outlook via Microsoft Graph.

> **Status:** planned — not yet functional. See [PLAN.md](PLAN.md).

## Usage

Microsoft Teams, OneNote and Outlook via Microsoft Graph via the `teams` keyword.

![Microsoft 365 results in Alfred](images/teams.png)

* <kbd>↩</kbd> Primary action.
* <kbd>⌘</kbd><kbd>↩</kbd> Secondary action.
* <kbd>⌘</kbd><kbd>Y</kbd> Quick Look.

Every keyword can be changed in the Workflow’s Configuration.

## Development

```bash
./build.sh   # -> dist/alfred-microsoft-365-<version>.alfredworkflow
```
